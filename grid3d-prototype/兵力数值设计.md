下面是一份可直接作为策划案/表格设计依据的 **塔防游戏数值设计参考文档**。核心思想是：把怪物压力、塔的防守能力、经济产出，全部折算成统一的 **兵力值 / Combat Value**。

**一、核心定义**
| 概念 | 定义 | 作用 |
|---|---|---|
| 兵力值 CV | 某单位或波次的综合战斗价值 | 用于比较怪物压力和玩家防守能力 |
| 怪物兵力 MCV | 一波怪物对玩家造成的总压力 | 决定这一波有多难 |
| 防守兵力 DCV | 玩家已建造塔/单位的有效防守能力 | 判断玩家是否能守住 |
| 经济值 EV | 玩家可用于建造/升级的资源总量 | 决定玩家理论成长速度 |
| 稳健系数 S | 容错倍率，常用 `1.10 ~ 1.25` | 给普通玩家留操作/随机误差空间 |

基础判断公式：

```text
是否能守住 ≈ 玩家有效防守兵力 DCV ≥ 本波怪物兵力 MCV
```

更完整一点：

```text
有效防守兵力 =
塔基础兵力 × 克制修正 × 范围修正 × 控制修正 × 站位修正 × 操作修正
```

---

**二、怪物兵力计算**
怪物兵力由三部分组成：

```text
怪物兵力 MCV =
血量压力
+ 输出压力
+ 机制压力
```

推荐公式：

```text
单怪兵力 =
K_hp × 有效血量
+ K_dps × 有效DPS × 参考战斗时间
+ 机制价值
```

整波怪物：

```text
本波怪物兵力 =
单怪兵力 × 怪物数量 × 数量形态系数 × 波次修正系数
```

| 因子 | 公式/说明 | 设计意义 |
|---|---|---|
| HP | 基础生命 | 决定需要多少输出才能清怪 |
| 护甲 | 提高有效血量 | 抗性越高，越难杀 |
| 有效血量 EHP | `HP / 承伤倍率` | 统一血量和防御 |
| 攻击力 | 平均攻击伤害 | 决定怪物杀塔/杀基地压力 |
| 攻击间隔 | `DPS = 平均攻击 / 攻击间隔` | 攻速越快，输出越高 |
| 移速 | 影响玩家清怪时间 | 越快越难守 |
| 数量 | 怪物总数 | 影响范围塔和单体塔价值 |
| 特殊机制 | 飞行、隐身、回血、分裂、护盾等 | 额外增加兵力 |

护甲转有效血量示例：

```text
承伤倍率 = 1 / (1 + 护甲减伤率)
有效血量 = HP / 承伤倍率
```

如果使用类魔兽公式：

```text
正护甲承伤倍率 = 1 / (1 + 0.06 × 护甲)
有效血量 = HP × (1 + 0.06 × 护甲)
```

**三、塔/防守单位兵力计算**
塔的兵力由输出、防御和功能组成：

```text
塔兵力 DCV =
输出价值
+ 防御价值
+ 功能价值
```

推荐公式：

```text
塔兵力 =
K_dps × 有效DPS × 覆盖时间
+ K_ehp × 有效血量
+ K_func × 功能价值
```

| 因子 | 公式/说明 | 设计意义 |
|---|---|---|
| 攻击力 | 平均伤害 | 基础输出 |
| 攻击间隔 | `DPS = 平均伤害 / 攻击间隔` | 攻速越快，价值越高 |
| 射程 | 影响覆盖时间 | 射程越长，能打更多轮 |
| 范围伤害 | 按命中数量折算 | 对群怪价值高 |
| 控制 | 减速、眩晕、击退 | 延长输出窗口 |
| 穿透/弹射 | 增加有效命中数 | 对密集怪收益高 |
| 对空/对地 | 限定攻击目标 | 目标限制会降低通用价值 |
| 特殊机制 | 暴击、燃烧、中毒、召唤等 | 折算为额外DPS或功能价值 |

有效DPS：

```text
有效DPS =
基础DPS
× 命中率
× 克制系数
× 范围命中系数
× 覆盖率
```

范围命中系数示例：

| 类型 | 建议系数 |
|---|---:|
| 单体塔 | 1.00 |
| 小范围AOE | 1.30 ~ 1.80 |
| 中范围AOE | 1.80 ~ 2.50 |
| 大范围AOE | 2.50 ~ 4.00 |
| 全屏/超大范围 | 需要单独限制冷却或伤害 |

**四、经济系统设计**
经济系统决定玩家理论上能拥有多少防守兵力。

```text
玩家可用经济 =
初始资源
+ 击杀收益
+ 波次奖励
+ 利息/收入
- 经济投资
- 消耗品/维修/技能消耗
```

每波目标防守兵力：

```text
目标防守兵力 =
玩家理论可用经济 × 防守投资比例 × 单位金币战力效率
```

例如：

| 波次 | 理论经济 | 防守投资比例 | 目标防守兵力 |
|---:|---:|---:|---:|
| 1 | 300 | 90% | 270 |
| 5 | 1000 | 80% | 800 |
| 10 | 2200 | 75% | 1650 |
| 20 | 7000 | 70% | 4900 |

经济投资比例越高，玩家越偏向贪经济；防守投资比例越高，玩家越稳。

推荐关系：

```text
普通波怪物兵力 ≈ 玩家理论防守兵力 × 0.90 ~ 1.00
硬波怪物兵力 ≈ 玩家理论防守兵力 × 1.05 ~ 1.15
Boss波怪物兵力 ≈ 玩家理论防守兵力 × 1.15 ~ 1.35
```

**六、因子删除规则**
如果删除某个属性因子，比如删除护甲、攻防克制、移速、控制抗性，需要遵循三个原则：

| 原则 | 说明 |
|---|---|
| 兵力守恒 | 删除因子后，不能让整体难度突然变高或变低 |
| 价值转移 | 被删除因子的价值要转移到其它因子上 |
| 基准重算 | 所有关联公式和表格需要重新校准 |

例如删除“护甲”：

原公式：

```text
有效血量 = HP × 护甲系数
怪物兵力 = K_hp × 有效血量 + K_dps × DPS × 时间
```

删除护甲后：

```text
有效血量 = HP
```

为了保持原兵力不变，需要补偿 HP：

```text
新HP = 原HP × 原护甲系数
```

例子：

| 原HP | 原护甲系数 | 原有效血量 | 删除护甲后新HP |
|---:|---:|---:|---:|
| 1000 | 1.30 | 1300 | 1300 |

也就是说，删除护甲不是直接把护甲拿掉，而是要把护甲带来的生存价值并入 HP。

**七、因子新增规则**
新增属性因子时，比如暴击、韧性、元素抗性、闪避、破甲、护盾，需要满足：

| 规则 | 说明 |
|---|---|
| 可量化 | 新因子必须能折算成 DPS、EHP、时间或金币价值 |
| 有中性值 | 乘法因子必须有默认值 `1.0`，加法因子默认值 `0` |
| 不重复计价 | 不能和已有因子重复计算同一部分价值 |
| 可控范围 | 因子必须有上限或递减收益 |
| 可被反制 | 强力机制最好有对应克制手段 |
| 可表格化 | 策划能在表里批量调参 |

例如新增“暴击”：

```text
期望伤害倍率 =
1 + 暴击率 × (暴击倍率 - 1)
```

塔DPS调整为：

```text
有效DPS =
基础DPS
× 暴击期望倍率
× 命中率
× 克制系数
× 覆盖率
```

例子：

| 暴击率 | 暴击倍率 | 期望伤害倍率 |
|---:|---:|---:|
| 10% | 200% | 1.10 |
| 25% | 200% | 1.25 |
| 30% | 300% | 1.60 |

**八、公式调整方法**
推荐把公式拆成两层：基础值 + 修正因子。

基础层：

```text
基础兵力 =
K_hp × EHP
+ K_dps × DPS × T_ref
```

修正层：

```text
最终兵力 =
基础兵力
× 移速系数
× 数量形态系数
× 克制系数
× 机制系数
```

新增因子时：

```text
最终兵力 =
原最终兵力 × 新因子系数
```

删除因子时：

```text
新基础属性 = 原基础属性 × 被删除因子的平均贡献
```

例如删除移速系数：

```text
原怪物兵力 = 基础兵力 × 移速系数
```

删除后：

```text
新基础兵力 = 基础兵力 × 原移速系数
```

然后再把新基础兵力分摊到 HP 或 DPS：

```text
新HP = 原HP × 70%补偿
新DPS = 原DPS × 30%补偿
```

**九、推荐校准流程**
1. 先定经济曲线：每波玩家理论有多少钱。
2. 再定目标防守兵力：玩家应该投入多少防守。
3. 再定怪物兵力：普通波、硬波、Boss波分别给倍率。
4. 再反推怪物属性：HP、数量、DPS、移速、机制。
5. 最后用实战模拟修正：看是否真的能守住。

核心公式：

```text
本波怪物兵力目标 =
玩家理论经济 × 防守投资比例 × 难度倍率
```

然后：

```text
怪物属性组合 → 计算出来的MCV ≈ 本波怪物兵力目标
```

数值设计最重要的不是公式复杂，而是所有属性最终都能回到同一个问题：

```text
这个东西大约值多少金币的战斗力？
```

只要能稳定回答这个问题，新增、删除、调整属性都会比较可控。
