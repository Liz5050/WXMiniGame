# Grid3D Combat Prototype

这是一个独立静态 Web 原型，用来验证 `Grid3D` 的核心玩法闭环：

```text
开始游戏 -> 配置少量战斗格 -> 构建放置即时充能 -> 行列消除触发开场技 -> 开始战斗兑现强化 -> 战斗胜利返钱 -> 回到构建
```

## 运行方式

直接打开：

```text
D:\Practice\WXMiniGame\grid3d-prototype\index.html
```

不需要 Cocos Creator，不需要安装依赖，也不需要启动 dev server。

也可以用任意静态 HTTP 服务访问，例如：

```powershell
cd D:\Practice\WXMiniGame\grid3d-prototype
python -m http.server 8080
```

然后打开：

```text
http://localhost:8080/
```

部署到云服务器时，把 `grid3d-prototype` 整个目录作为静态站点根目录即可。所有资源路径都是相对路径，可以直接放到 Nginx、Caddy、对象存储静态网站或任意静态托管服务。

## 操作

- 点击“开始游戏”初始化棋盘和金币；游戏中该按钮会变为“重置游戏”，再次点击会弹出二次确认，确认后清空所有局内状态并回到初始界面。
- 点击候选方块，再点击棋盘放置；放置本身免费，但每次放置消耗 1 点构建行动。3 个候选全部放完后可点击“刷新方块 2金”换下一组，刷新同样消耗 1 点构建行动。
- 构建阶段会显示已放置方块，并在棋盘左侧显示行等级/行经验、底部显示列等级/列经验；战斗阶段会隐藏这些构建信息，只保留战斗格标识、核心和战斗单位/敌人。
- 点击“旋转方块 R”或按 `R` 旋转当前方块。
- 点击单位按钮，再点击非核心棋盘格，可把该格配置成战斗格；未选择方块/单位时点击格子可查看地块信息。
- 初始指挥上限为 3，之后每 3 轮指挥上限 +1，最高 6。上限未提升前需要优先强化现有单位。
- 指挥上限允许时，近战守卫 10 金、远程射手 12 金、修复师 10 金；更换单位约为目标单位造价的 35%，最低 4 金。
- 方块覆盖战斗格会给该格充能，正交相邻战斗格也会获得少量充能；满行/满列会扫过对应行列，为命中的战斗格充能并增加开场技次数。
- 点击“开始战斗”进入自动战斗阶段。
- 战斗开始时会先投放少量敌人，再让有开场技次数的战斗格立即释放技能，方便观察构建成果。
- 敌人全灭后会自动结算金币并回到构建阶段；金币栏小字显示当前构建行动和指挥使用量。
- 核心生命归 0 后本波战斗失败，不清空整局数据，而是回溯到本轮构建开始时的状态，可以重新调整放置和单位配置后再次开战。
- 核心据点和远程射手都有弹道表现，二者颜色与形态不同，方便观察输出来源。
- 金币不足、方块越界、格子已占用、核心格不能配置单位等非法操作会给非打断式飘字提示，并取消当前选中的方块或单位；重置确认使用页面内弹窗，不使用 `alert`。

手机浏览器已做竖屏适配：棋盘保持正方形，候选方块横排，按钮触控区域不小于 44px。

## 当前规则

- 棋盘固定为 10x10。
- 中央 2x2 是核心据点，可以放置构建块并参与行列消除经验积累，但不可配置战斗单位。
- 初始金币为 36。
- 利息规则已停用；当前版本优先验证“放置/消除马上变强”的即时塔防爽感。
- 每轮构建行动有限：初始 2 点，每 4 轮 +1，最高 4 点；放置方块和刷新候选各消耗 1 点，行动用完后应进入战斗验证。
- 敌人波次不再使用固定数量，而是先按理论经济 EV 推出推荐怪物兵力 MCV，再用当前防守兵力 DCV 做宽松夹取；目标战斗时长约 8-18 秒，敌人单体保持低血低攻，强度主要转化为数量。
- 每波计划收入会拆成击杀收益和胜利奖励：击杀收益池约占 45%，按敌人数量折算到每个怪；胜利奖励约占 55%，用于保证经济曲线不被怪物数量直接放大。
- 放置构建块不消耗金币；每组 3 个候选方块全部放完后，刷新下一组消耗 2 金币和 1 点构建行动。
- 已放置构建块使用其候选方块颜色显示，仅在构建阶段可见。
- 每个战斗格有 0-12 点充能：0-1 为 I 阶，2-5 为 II 阶，6+ 为 III 阶；充能满后继续获得的能量会转为精通，精通继续提升单位质量。
- 放置方块直接覆盖战斗格时，该格充能 +3；覆盖格的正交相邻战斗格充能 +1；同一次放置对同一战斗格只取最高影响。
- 满行/满列消除时，命中的战斗格充能 +4，并获得 1 次开场技，开场技最多储存 3 次。
- 满行/满列消除不再产出金币，只服务于战斗格充能、开场技和行列经验，避免玩家为了经济无限拖在构建阶段。
- 满行会清除该行构建块，并从该行最左侧开始填满 1 个行经验格。
- 满列会清除该列构建块，并从该列最下侧开始填满 1 个列经验格。
- 单条行/列累计填满 10 个经验格后，该行/列等级提升 1 级，并清空该行/列经验槽。
- 战斗单位生成时会根据所在格子的有效等级提升属性；有效等级由该格所在行等级和列等级共同决定。
- 普通格转战斗格受指挥上限限制：初始 3 个，每 3 轮 +1，最高 6；近战守卫 10 金、远程射手 12 金、修复师 10 金；更换单位约为目标单位造价的 35%，最低 4 金。
- 战斗格每轮战斗只召唤 1 个单位。
- 单位类型包括近战守卫、远程射手、修复师。II/III 阶和精通会从攻击力、攻击速度、攻击范围、防御、血量和技能伤害多维度提升单位质量。
- 近战获得高额减伤、顺劈和 III 阶倒地震爆；射手从单体射击变成多目标齐射，III 阶会周期性发射大量弹幕清屏；修复师获得扩散治疗和支援脉冲。
- 我方战斗单位索敌范围覆盖整张棋盘；范围内没有敌人时会回到核心据点周围守卫，不显示索敌范围。
- 核心据点有自动炮击；核心生命归 0 时回溯到本轮构建开始时的检查点，通常是上一波胜利结算后刚回到构建阶段的状态。

## 文件

- `index.html`：页面结构。
- `src/styles.css`：界面样式。
- `src/game.js`：状态、构建消除、战斗模拟、Canvas 绘制和输入控制。
